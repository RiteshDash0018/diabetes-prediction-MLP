# Diabetes Prediction using Multilayer Perceptron

This project develops a machine learning system for predicting diabetes using the Pima Indians Diabetes Dataset.

## Models Used

- Logistic Regression
- K-Nearest Neighbors (KNN)
- Support Vector Machine (SVM)
- Random Forest
- Multilayer Perceptron (MLP)

## Final Model

The final model is a tuned Multilayer Perceptron (MLP) developed for diabetes prediction.

## Technologies Used

- Python
- Google Colab
- Pandas
- NumPy
- Scikit-learn
- TensorFlow/Keras
- Keras Tuner
- Streamlit

## Dataset

The project uses the Pima Indians Diabetes Dataset.

## Deployment

The trained MLP model was deployed using Streamlit.

The application allows users to enter patient information and obtain a model-based diabetes prediction.
